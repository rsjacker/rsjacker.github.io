# Rohit Kumar — Finance Portfolio Website

## Publish free with GitHub Pages
1. Create a free GitHub account if you do not already have one.
2. Create a new **public** repository. A good name is `rohit-kumar-portfolio`.
3. Upload **all files and folders from this package** (do not upload only `index.html`).
4. In the repository, go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. GitHub will show your free website address after deployment.

For the cleanest free address, create a repository named exactly `<your-github-username>.github.io`. Then your site address will be `https://<your-github-username>.github.io/`.

## Help Google find it
After the site is online:
1. Add the exact website URL to your LinkedIn Contact Info.
2. Add the exact website URL to your CV.
3. Open Google Search Console and add the website as a property.
4. Use URL Inspection and request indexing for the home page.

The site already includes a search-friendly title, description and Person structured data.

## Updating certificates
Put new PDF certificates in `assets/certificates/`, then add or update the corresponding certification card in `index.html`.
